# Assignment 1: Data Collection Memo

## Goal

Turn the Walker replication into a concrete data collection plan.

## Submit

- A list of institutions you are responsible for.
- One completed CDS extraction row per institution-year assigned so far.
- A note explaining where the CDS file came from.
- One AI prompt log entry if you used AI.

## Checks

- Every row has a year.
- Every row has male and female applicant counts.
- Every row has a URL or local source path.
- You can explain whether the institution is in a ban state or control state.
